本頁章節
開啟完整圖層組合各層獨立的領域、版本與選取規則自訂來源操作範例檔案、進度與復原

一次開啟多個 Navigator JSON 圖層#

開啟完整圖層組合#

  1. 選擇 File → Import Navigator Layer… 或按 Ctrl+Alt+O。這與 Studio JSON 的開啟／Ctrl+O 分開。
  2. 選擇本機 Navigator JSON，內容可以是單一圖層物件，或 1–20 個圖層的陣列。支援 UTF-8／BOM 與 UTF-16／BOM，檔案上限 10 MiB。所有圖層先完成格式驗證才開啟；任一圖層格式損壞會拒絕整份檔案。
  3. 預設勾選全部圖層。按 全選圖層 勾選整份清單，或 取消全選圖層 清空；也可個別勾選明確的子集合。
  4. 點擊一列，或透過 圖層預覽 切換詳細內容。清單顯示各層名稱、領域／版本、來源資料集及就緒／錯誤狀態。對截斷的狀態或資料集欄位懸停，可閱讀完整文字。同名圖層仍分開列出。
  5. 所有勾選圖層都就緒後，按 開啟勾選圖層，一次開成各自獨立的檔案分頁。依 JSON 順序加入，第一個勾選圖層成為作用中文件；原有分頁、選取與註記皆保留。

只有明確取消勾選的圖層才會排除；程式不會為了通過錯誤而偷偷少開某層。未勾選任何圖層時不能開啟。工作區最多 50 份文件，若整批加入會超過上限，整批拒絕。

各層獨立的領域、版本與選取規則#

每層依自己的官方或自訂領域、確切版本與資料集識別解析；自訂領域定義與 ID 映射來自確切 Bundle。切換預覽焦點會還原該層自己的版本及選取規則，不會切換主工作區目前文件。

已記錄的 ATT&CK 版本不能改用其他版本；本機已驗證快照會自動預覽，即使與目前文件不同。缺少官方快照時，可明確按 載入勾選圖層的版本／預覽，透過既有版本載入器驗證／下載快取，不切換官方 active.json／latest.json 指標。未記錄版本的圖層可個別選擇快照，預設先用目前版本，清單會標示其使用預覽中選定的版本。

Select techniques 的規則各層獨立：

  • Enabled rows / saved Studio selection：有 Studio 納入標記時還原該選取，與啟用狀態分開。
  • All listed rows：納入所有可解析資料列，包含停用技術。
  • Rows with a score or color：納入可解析且有分數／顏色的列；0 也算分數。

目前預覽會統計不重複選取 TTP 數與無法解析資料列數。未知／已停用 ID 與 Tactic 不匹配列仍保留為註記，但不納入選取。註解、小數分數、顏色、啟用狀態、Links、Metadata、自訂欄位與各 Tactic 註記均保留。同名圖層有不同文件 UUID，不會合併。

自訂來源#

含 x_ttp_studio_dataset 的圖層，會使用確切已載入資料集，或 <project-root>/data/attack/custom/<sha256>.json 中經雜湊驗證的 Bundle；領域與記錄版本也必須匹配。該自訂快取尚未開成分頁也能解析。

舊圖層只有 customDataURL 時，若已有唯一一份來源字串、版本與領域均相符的已載入自訂資料，就能自動解析。若相同來源對應不同資料集雜湊，須明確選擇來源。缺少 Bundle、雜湊不符、沒有該領域或版本不相容時，會在對應列顯示原因，並阻擋全部勾選圖層；不會改用官方同版本資料代替。

要補齊缺少的自訂資料，保持預覽開啟，點選該圖層後按 解析自訂資料…，取得網址、瀏覽本機 Bundle 或驗證選定快取。Collection Index 須明確選版本；確認領域／版本、預期／實際雜湊、最終來源與未解析列後，按 使用已驗證的 Bundle 綁定該層。雜湊變更須明確確認取代；不會自動下載網址，取消保留先前綁定。詳見來源解析手冊。

操作範例#

一份檔案包含 Enterprise v20.0、Mobile v11.3、自訂 ICS，以及名稱與第一層相同的另一個 Enterprise 圖層。保持四層勾選，逐一檢視領域／版本／來源，補齊缺少快照後，按一次 開啟勾選圖層，就會依陣列順序開啟四個獨立分頁。

若缺少自訂 ICS Bundle，全部勾選圖層都不會開啟。可補齊 Bundle 後重試，或明確取消勾選那一層，只開另外三層。按取消則一層都不開。再次匯入同檔案會建立另一組獨立文件，但仍受 50 份文件上限限制。

檔案、進度與復原#

輸入 JSON 以絕對路徑顯示。預覽會宣告無輸出檔案，讀取資料集時另列確切 Bundle／manifest 輸入絕對路徑。進度包含 1/5 讀取／驗證 → 2/5 逐層解析 → 3/5 預覽結果 → 4/5 驗證所有勾選草稿 → 5/5 一次安裝整批分頁。下載快照前會先列出快取／暫存輸出絕對路徑。資料準備與文件安裝分開：取消準備可能保留已成功驗證的快取，但不會留下只安裝一部分的文件組合。

延後讀檔工作開始前取消，會阻止檔案讀取；解析／草稿準備途中取消，會在工作檢查點停止。驗證失敗不開任何文件；插入分頁失敗會移除已插入分頁，還原舊文件清單與作用中分頁。匯入不寫 Studio 儲存檔或交換輸出檔；後續正常工作階段檢查點會保存新文件及其領域、版本、資料集，仍應主動儲存 Studio 原稿。

驗證：使用專案 Python 設定 QT_QPA_PLATFORM=offscreen 後執行 audit_navigator_bundle.py。測試讀取快取官方版本與隔離自訂 fixture，先列出輸入／輸出絕對路徑，再將範例、預覽截圖及 audit.json 寫到 <project-root>/artifacts/navigator-bundle。涵蓋混合版本／領域、同名、個別規則、自訂來源不明確／雜湊失敗、取消、整份／草稿拒絕、回滾、上限與 Studio／Navigator／工作階段往返。
