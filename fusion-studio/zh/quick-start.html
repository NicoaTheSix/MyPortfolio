快速開始#

以下操作保留最新版根 README 的英文原文；繁體中文詳細安裝請見 安裝與啟動。

Quick start#

Windows PowerShell: install Python 3.11 first, then run the following from a writable project folder. Initial dependency and dataset downloads need internet access; cached-data browsing works offline. For Linux or WSL2, follow the dedicated installation steps.

1. Get the source. Clone it, or select Code → Download ZIP on the repository page, extract it and open PowerShell in the extracted folder if Git is unavailable.

powershell
git clone https://github.com/NicoaTheSix/MITREATTACK_SIMULATOR.git
Set-Location -LiteralPath '.\MITREATTACK_SIMULATOR'

2. Create the local Python environment and install dependencies. No environment activation is required.

powershell
Write-Output ('Input requirements: ' + (Resolve-Path '.\requirements.txt').Path)
Write-Output ('Output Python environment: ' + (Join-Path (Get-Location).Path '.venv'))
py -3.11 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r '.\requirements.txt'
& '.\.venv\Scripts\python.exe' -m pip check

3. Prepare local datasets. On a fresh checkout, use the scripts below to prepare ATT&CK, ATLAS and CAR. Skip a downloader when your copy already contains that dataset and its valid source manifest/pointer. Each script reports its source, absolute output paths and stage progress; wait for successful completion before launching.

powershell
& '.\.venv\Scripts\python.exe' -B '.\scripts\download_attack_data.py'
& '.\.venv\Scripts\python.exe' -B '.\scripts\download_atlas.py'
& '.\.venv\Scripts\python.exe' -B '.\scripts\download_car.py'

4. Launch Fusion Studio. Run this command again for later launches, keeping the terminal open while using the application.

powershell
& '.\.venv\Scripts\python.exe' -B '.\main.py'

After setup, you can optionally register the fusionstudio Windows command or the Linux/Bash/Zsh command. These commands launch the desktop application. For Python-path alternatives and common installation failures, see Installation.

Your first research document#

  1. Wait for dataset loading to complete, then choose File → New File (Ctrl+N) to start a separate document. A normal launch may restore previous work.
  2. In the ATT&CK TTP sidebar, search for T1059.001 (PowerShell) and check it to include it. Add T1082 or another technique relevant to your topic.
  3. Review the included techniques in Workplace. A single click highlights a row; use its right-click menu to view information or edit a TTP annotation.
  4. Choose File → Save As… (Ctrl+Shift+S), keep all content types checked, and save a Studio JSON file. Close that document and use File → Open Studio JSON… (Ctrl+O) to continue it later.
  5. Use Export JSON / CSV… to create a CSV for reading or sharing. CSV and Navigator JSON are exchange formats; keep the Studio JSON for complete editable research.

Checking a technique includes it in your research document; it does not execute the behavior or establish detection coverage. The operating manuals cover matrix selection, annotations, ATLAS, CAR and supported export formats.
