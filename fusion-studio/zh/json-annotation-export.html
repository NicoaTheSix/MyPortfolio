Navigator JSON 註記匯出#

選擇完整或可見註記#

  1. 先依需求調整作用中矩陣的平台、搜尋與子技術展開狀態。
  2. 選擇 File → Export Navigator Layer…；或 Navigator → Export all open layers… 將 1–20 個圖層匯出成 JSON 陣列。
  3. 選定檔名後，檢視視窗顯示輸出絕對路徑、各圖層隱藏但已修改的格子數、不重複技術 ID 數，以及受影響 ID／Tactic 的唯讀清單。
  4. 只匯出可見技術的註記 預設不勾選，完整保留全部註記；每次開啟都會回到此預設。
  5. 只有希望此次交換副本省略隱藏技術註記時才勾選，再按 匯出 JSON。按 取消 不寫入任何檔案，也不覆寫既有目標。

此處「已修改」表示與技術預設狀態不同，不是指上次儲存後才編輯。包含分數（0 也計算）、手動色、停用狀態、註解、Links、使用者 Metadata、showSubtechniques: true 及技術列的自訂欄位；匯入的註記也計算。Studio 單純記錄納入的保留 Metadata、唯讀來源 STIX Notes 不計入。每個技術／Tactic 位置計一次，另一欄顯示不重複技術 ID 數。無法解析的匯入 ID／Tactic 列視為隱藏，依原範圍列出。

可見範圍的定義#

作用中圖層依實際矩陣的邏輯顯示格子判定，包含平台聯集、搜尋、Hide disabled、全域／個別展開及搜尋暫時展開。父技術可見但子技術收合時，子技術仍視為隱藏；作為家族標頭顯示的父技術則為可見。捲動到畫面外、關閉／切離矩陣分頁、隱藏填色／提示、來源懸停暫時外框都不會讓註記被省略。作用中矩陣仍在建立時，依相同平台／搜尋控制與已儲存展開設定投影。

全部圖層匯出時，其他圖層各自使用保存的平台篩選、啟用狀態與展開設定，不套用作用中搜尋。Overlay 不會將別層註記寫進目前圖層。名稱、排序、圖層 Description、漸層、圖例、圖層 Links／Metadata 等屬性均完整保留。

只匯出可見註記時，全域註記會轉為明確 Tactic 列，避免可見位置的全域註解／顏色在重新匯入後回流到隱藏 Tactic。既有個別 Tactic 列以整列優先，與矩陣一致。隱藏但已選取的技術仍保留識別資料與 Studio 納入標記，因此可能出現在 JSON，卻不含註解、顏色、分數、Links 或使用者 Metadata。選取範圍完整保留，不會因隱藏而取消 TTP。若省略隱藏的停用狀態註記，該交換副本就不再停用那個位置。

此選項只控制技術註記，不是機密資料去識別工具；圖層屬性與自訂擴充欄位仍完整保留。Studio JSON 儲存／另存新檔／匯出、CSV、工作階段復原、SVG、Excel 的規則都不變。需要完整 Domain、版本封存及可編輯原稿時，請保留 Studio 儲存檔。

操作範例#

替 T1053.005 Scheduled Task 新增註解與分數，再收合 T1053 Scheduled Task/Job，匯出 Navigator JSON。預設完整保留時，隱藏子技術的註記仍在，檢視視窗列出其隱藏 Tactic 位置。勾選只匯出可見註記後，交換副本不含該子技術註記；如果原先有選取，Studio 納入標記仍能在重新匯入時還原選取。再次開啟匯出視窗時，預設又是完整保留。

若同一技術有全域註解，卻只有其中一個 Tactic 可見，精簡副本只在可見 Tactic 列保留註解。原圖層仍保有全域註記與所有選取範圍。

檔案、進度與失敗處理#

輸入為記憶體中的開啟文件、相同版本／Domain 的快取 catalog 及凍結矩陣控制，不進行網路下載。處理前，Output 先顯示輸出絕對路徑。預覽依序顯示 1/3 驗證 → 2/3 解析技術／Tactic 列 → 3/3 隱藏數量。匯出列出保留策略，再顯示輸出／暫存絕對路徑與 1/3 序列化 → 2/3 寫入 UTF-8 → 3/3 原子發布。取消檢視不建立輸出或暫存檔；發布失敗會保留原有目標並清除暫存檔。

原名稱、註記、選取、儲存基準與已儲存／未儲存狀態都不變。單層匯出成功會記住交換輸出檔名／格式，全部圖層匯出則不變更這些紀錄。核取選項只對此次有效，不另存成圖層或工作階段偏好。程式化明確傳入 visible_only=True 使用同一投影；省略時完整保留，並在操作紀錄提醒隱藏數量。

驗證：使用專案 Python 設定 QT_QPA_PLATFORM=offscreen 後執行 audit_json_annotation_export.py。測試在建立隔離 fixture、範例匯出、Studio 資料、截圖及 audit.json 前列出絕對路徑，產物位於 <project-root>/artifacts/json-annotation-export。
