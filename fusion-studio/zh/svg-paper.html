SVG 紙張尺寸與方向#

開啟 **Navigator → Export matrix SVG…（匯出矩陣 SVG）**並指定位置，再到 設定 → 影像與標頭區選擇「紙張尺寸」「方向」及「單位」。初始仍是「自訂」、寬高自動，延續既有匯出預設。

選擇預設紙張#

紙張尺寸 直式尺寸（英吋） 直式邏輯像素
美式 Letter 8.5 × 11 816 × 1056
美式 Legal 8.5 × 14 816 × 1344
小型 11 × 17 1056 × 1632
中型 18 × 24 1728 × 2304
大型 24 × 36 2304 × 3456

「直式」將短邊放在水平方向，「橫式」互換兩軸。選預設紙張後會固定畫布尺寸，寬高輸入欄暫時鎖定；改紙張或方向時，數值會依目前單位更新。標頭高度、字型、主題、圖例、框線及子技術設定均保留。

紙張預設設定的是 SVG 畫布。既有繪製流程會將完整矩陣縮放至標頭下方可用空間。Flat／Side／Mini、淺色／深色、全部／已展開／不顯示子技術，以及擷取的平台與搜尋條件都可一起使用。

單位與實際尺寸#

可選 px／cm／in，換算基準為每英吋 96 邏輯像素、2.54 公分。因此 Letter 直式分別為 816 × 1056 px、21.59 × 27.94 cm 或 8.5 × 11 in；橫式則互換兩軸，實際紙張相同。

視窗以標準實際長度保留數值，多次切換單位不會累積顯示四捨五入誤差。標頭高度與圖例 X／Y／寬／高也保留實際尺寸。輸入上限隨單位換算，每個長度仍最多 100000 邏輯像素。欄位顯示六位小數，匯出則使用保留的實際值，包含上限數值。

預覽分頁會配合視窗縮放顯示；輸出的實際尺寸以 SVG 根節點的寬高單位及 96-DPI viewBox 為準。

返回自訂尺寸#

選回「自訂」會還原最近一次編輯的自訂寬高與方向，即使中途換過單位或多種預設紙張也一樣。紙張預設不會覆寫該草稿，回到自訂後可重新編輯寬高。

  • 任一軸設 0，保留原本「自動」行為。
  • 寬高皆大於零時，方向控制可使用，並反映明確尺寸；切換方向會交換一次寬高。
  • 任一軸為自動時，方向控制停用，該軸由矩陣內容決定。
  • 手動編輯尺寸會更新方向顯示，不會暗中旋轉輸入值。
  • 原本自訂寬高皆自動時，經過預設紙張後再返回，仍會還原原始自動設定。

要使用 A4 大小，可選自訂及 cm，填寬 21、高 29.7，再選橫式交換為 29.7 × 21。這沿用一般自訂尺寸功能。

保留標頭與圖例設定#

改紙張／方向會保留原有實際尺寸與位置，不會自動搬移或縮小獨立定位的圖例。若圖例因此超出畫布，預覽／匯出會顯示既有驗證錯誤，請調整位置／大小或選較大紙張。明確標頭高度也須讓矩陣至少剩 40 邏輯像素。預覽失敗後仍可修正設定，且不會寫檔。

範例：Letter 橫式報告#

  1. 開啟 SVG 匯出並選「美式 Letter」。
  2. 選「橫式」及 in；寬高顯示 11、8.5 並鎖定。
  3. 標頭高度填 1.25 英吋，選擇 SVG 主題，圖例維持固定於標頭。
  4. 按「預覽 SVG · 不寫入檔案」，檢查完整矩陣。
  5. 按「匯出 SVG」；根節點為 width="11in"、height="8.5in"、viewBox="0 0 1056 816"。
  6. 若改用自訂畫布，選回「自訂」後調整已還原尺寸，修改後重新預覽。

相同擷取畫面與設定的預覽／輸出位元組完全一致。取消視窗不寫檔。紙張與方向只屬本次匯出視窗，不改寫圖層 JSON、TTP 選取／註記、儲存標記或 Excel；重開視窗仍從自訂／自動開始。

程式呼叫#

python
from matrix_exports import export_matrix

# document 已載入；report 接收階段進度。
export_matrix(document, output_path, 'svg', report,
              svg_options={'size': 'letter', 'orientation': 'landscape'})

有效尺寸 ID 為 custom、letter、legal、small、medium、large，方向為 portrait／landscape。省略尺寸時預設自訂。紙張依指定單位解析；有效的明確寬高會被紙張尺寸取代，但不合法數值仍拒絕。自訂以明確寬高為準，後端由正值推導方向，不旋轉舊 API 輸入；程式若要旋轉自訂畫布，請交換寬高。

所有長度皆使用所選單位。程式直接指定 unit='in' 或 'cm' 時，請一併提供想要的其他長度，例如 legend_width；介面切換單位時會自動換算原有長度。

程式流程與驗證#

預覽前明示記憶體輸入／無輸出檔，再顯示「SVG Preview 1/3 驗證 → 2/3 繪製 → 3/3 完成」。匯出前先列目的／暫存檔的絕對路徑，再依「Matrix Export 1/4 投影 → 2/4 繪製 → 3/4 寫入 → 4/4 原子發布」進行。不合法尺寸、內容超界、取消或發布失敗都保留原輸出並清除暫存檔。

svg_sizing.py 定義實際紙張、換算與方向規則 → export_dialogs.py 保存標準實際長度與獨立自訂草稿 → svg_export.py 驗證及解析紙張尺寸 → layer_analysis_dialogs.py 執行共用預覽／匯出流程 → matrix_exports.py 原子寫入 SVG。既有呼叫者仍可使用 svg_export.UNITS。各模組於根目錄 README 記錄流程。

在專案根目錄執行：

powershell
$env:QT_QPA_PLATFORM = 'offscreen'
& '.\.venv\Scripts\python.exe' -B '.\audit_svg_paper.py'

離線驗證先列輸入／輸出絕對路徑，依序測快照 → 每種紙張／方向／單位的實際 SVG XML／Qt 繪製 → 自訂／自動／標頭／圖例／排版／主題 → 原生控制／單位往返／草稿還原／上限 → 雙語預覽／匯出一致及取消 → 發布錯誤與來源保留 → 發布 artifacts/svg-paper/audit.json。同目錄包含 30 份紙張 SVG 範例、settings-en.png、settings-zh.png、preview.png 與 native.svg。已登錄 scripts/audit_linux.py，登錄本身不代表另已完成原生 Linux 驗證。
