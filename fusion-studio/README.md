# Fusion Studio 文件網站

此目錄提供可直接由 GitHub Pages 發布的靜態技術文件。操作手冊唯一主要維護來源為 `NicoaTheSix/MITREATTACK_SIMULATOR` 的 `manual/`；`zh/`、`en/`、`assets/`、`index.html`、搜尋索引及來源清單由根目錄 `build-fusion-docs.mjs` 產生，請勿人工修改生成內容。`docs.css`、`docs.js` 是網站介面，其運作流程見下方。

## 建置與來源

在 MyPortfolio 根目錄使用 Node.js 20 以上及 `npm ci` 準備固定依賴，再執行：

```powershell
node .\build-fusion-docs.mjs --source 'D:\MITREATTACK_SIMULATOR'
node .\check-fusion-docs.mjs
```

建置器執行前列出來源專案、原始手冊及網站輸出目錄的絕對路徑。依序執行來源盤點、版本及雜湊記錄、必要素材收集、雙語 HTML 轉換、搜尋索引與來源清單生成。只讀來源 repo，不執行應用程式、不修改 F1 手冊、設定、資料集或工作階段。不發布完整 `data/`、虛擬環境或測試日誌。

每個生成頁面顯示原始檔路徑、基準 commit、是否有尚未提交內容與產製日期。`source-manifest.json` 記錄實際收錄來源及 SHA-256；`build-report.json` 記錄轉換、別名與排除項目。未提交內容以該次本機快照為準，不能宣稱已存在於該 commit。網站沒有另一套手動維護的操作手冊。

## 閱讀介面流程

1. HTML 提供完整文章、分類側欄、頁內目錄與上一篇／下一篇，關閉 JavaScript 仍可閱讀和換頁。
2. `docs.js` 先在瀏覽器主控台列出目前頁面、搜尋 JSON 的絕對 URL；輸出為目前頁面 DOM／剪貼簿，不寫入檔案。接著回報導覽、程式碼複製、搜尋三階段進度。
3. 中英文切換維持相同主題；來源只有單一語言的補充資料會標明保留原文。
4. 搜尋只讀取本網站的靜態索引，依目前語言搜尋全文／標題；結果使用文字節錄與實際頁面／章節連結，沒有外部搜尋服務或使用者追蹤。
5. 手機版可用「文件目錄」按鈕展開／收合側欄。右側頁內目錄於窄畫面變成文章前可展開的區塊。
6. 程式碼按鈕複製其相鄰區塊；剪貼簿不可用時顯示手動複製提示。
7. `studio://` 轉為桌面操作提示，網頁不註冊或執行程式專用協定。`#_2` 等原程式錨點由建置器映射至對應章節；原手冊不改動。

## 素材、連結與授權

網站只收錄指南實際引用的公開範例、圖片，以及介紹／示範影片、字幕與研究範例。影片不自動播放，使用瀏覽器原生播放器，預設不下載完整影片。原始程式碼、開發驗證與非發布文件連至來源 repo；未提交且未納入發布範圍的開發附件顯示為參考文字，避免產生不存在的網址。

Fusion Studio 原創程式及文件依來源專案授權；MITRE ATT&CK®、ATLAS、CAR、Qt 等維持各自出處及授權。本網站不是 MITRE 官方產品或背書。CAR 內容為研究參考，網站沒有攻擊執行、SIEM 查詢執行或偵測部署功能。Canvas、CWE 規劃不列為可操作指南。

## 驗證與預覽

根目錄 `check-fusion-docs.mjs` 列出絕對輸入／輸出位置並檢查：全部雙語指南收錄、所有本地頁面／錨點／圖片／下載、語言對應、來源雜湊清單、搜尋索引及程式專用協定清除。完整驗證結果寫入本目錄 `validation-report.json`。

啟動預覽後，亦可加上 `--url 'http://127.0.0.1:4173/MyPortfolio/fusion-studio/'`：每批比對實際 HTTP 回應與本次產物，檢查影片 Range/MIME 與開發檔案拒絕存取。這個模式需要本機網路連線權限；不檢查或宣稱所有外部來源網站的存取權限。

根目錄執行 `node .\serve.mjs` 後開啟 `http://127.0.0.1:4173/MyPortfolio/fusion-studio/`。以 `/MyPortfolio/` 子路徑測試相對資源，另以瀏覽器檢查搜尋、程式碼複製、中英切換、手機側欄及影片。

生成檔隨 MyPortfolio 原始碼提交與發布。GitHub Pages 設定沿用擁有者既有設定；此建置不修改部署來源或網域。
