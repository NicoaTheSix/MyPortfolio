Your first research#

Your first research document#

  1. Wait for dataset loading to complete, then choose File → New File (Ctrl+N) to start a separate document. A normal launch may restore previous work.
  2. In the ATT&CK TTP sidebar, search for T1059.001 (PowerShell) and check it to include it. Add T1082 or another technique relevant to your topic.
  3. Review the included techniques in Workplace. A single click highlights a row; use its right-click menu to view information or edit a TTP annotation.
  4. Choose File → Save As… (Ctrl+Shift+S), keep all content types checked, and save a Studio JSON file. Close that document and use File → Open Studio JSON… (Ctrl+O) to continue it later.
  5. Use Export JSON / CSV… to create a CSV for reading or sharing. CSV and Navigator JSON are exchange formats; keep the Studio JSON for complete editable research.

Checking a technique includes it in your research document; it does not execute the behavior or establish detection coverage. The operating manuals cover matrix selection, annotations, ATLAS, CAR and supported export formats.

Example files#

Start with the files produced by the real usage demonstration:

Example What it contains How to use it
Editable research document — Studio JSON ATT&CK and ATLAS technique selections, plus independently included CAR content Download/save the file, then choose File → Open Studio JSON…. Keep all content types checked to inspect the complete example.
ATT&CK technique list — CSV The two ATT&CK techniques exported by the demonstration, with tabular research fields Open it in a spreadsheet or text editor. It is a sharing example, not a complete Studio backup.
Walkthrough, timestamps and storyboard The steps that produced the files and the matching video Follow the sequence, then create your own document.

Dataset versions matter: the example records ATT&CK 20.0 and the ATLAS 2026.09 snapshot, alongside its CAR source identity. If opening reports a missing ATT&CK release, use Version to download that exact release and retry; downloading the latest release alone does not guarantee every saved document's version is cached. The ATLAS/CAR downloaders above prepare the project's pinned sources. See Studio files and dataset requirements (繁體中文) for portability and missing-cache behavior.
