鼠尾草綠樣板

在 Windows 系統匣開啟「桌面配置」，選擇「從鼠尾草綠樣板建立…」。雙擊六角形筆記即可編輯文字。三角形照片可更換圖片，也可拖曳或縮放裁切。25 分鐘倒數預設為暫停。

  • 加入鼠尾草綠樣板與照片裁切調整。矩形支援分開設定寬高，並可設定標籤。

選擇適合的平台

Windows

原生 C++17／Win32／GDI+。支援文字、圖片、計時器與鬧鐘，繁體中文／English 即時切換，以及需明確同意的登入啟動。

Windows 使用說明 ↗
Windows 計時與啟動

程式執行時，其他桌面配置的計時器與鬧鐘也會繼續運作。程式完全關閉期間不會提醒。登入啟動預設關閉，須由使用者明確同意。

macOS

原生 AppKit 與 C++ 核心，支援文字、圖片、計時器、多選拖曳、吸附與 JSON 配置。介面為中文；尚未提供 Windows 版的鬧鐘、雙語切換或登入啟動功能。

Universal 2 包含 Apple silicon 與 Intel 架構，但 Intel 實機、多螢幕及其他 macOS 版本仍待驗證。套件採 ad-hoc 簽章，尚未經 Apple 公證。

配置相容性：Windows 匯出 v3 並讀取 v1–v3；Mac 僅匯出及讀取 v1/v2，尚不能直接匯入 Windows v3，即使沒有鬧鐘亦同。Mac v2 可由 Windows 匯入。

Mac 使用說明與限制 ↗

三種形狀，自由拼排

文字、圖片與計時

把備忘、照片與工作時間放進六角形、三角形或矩形。

多選、拖曳與吸附

Shift 多選後整組移動，靠近其他格時吸附。

調整外觀

設定尺寸、字體、透明背景與實色、像素、RGB 或呼吸邊框。

配置備份與搬移

以含圖片的 JSON 匯出，支援覆蓋或合併匯入；Windows v3 目前無法直接匯入 Mac。

下載後開始使用

兩平台更新前都先結束舊程式，完整解壓縮新套件。Windows 開啟 DeskTiles／DeskTiles.exe；Mac 開啟 DeskTiles.app。關閉控制面板只會隱藏視窗；請從程式選單儲存並結束。

驗證範圍與限制

專案交付紀錄：Windows 228 項核心、192 項解壓整合及 38 項配置／CLI 檢查；Mac 170 項核心、Universal 2 架構、圖示載入與簽章檢查。網站發布者核對套件與來源雜湊，沒有在此重新執行應用程式測試。

專案已實測重新啟動後，背景配置的鬧鐘按時觸發。Mac 尚未經 Apple 公證，Intel 實機及多螢幕仍待驗證。Linux 版尚未提供。
