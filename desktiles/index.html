桌面拼格DeskTiles

桌面上的一小格，留給重要的事。

把想記住的文字、圖片與時間，放進可以自由拼排的小格子。選一個形狀，為桌面留一點自己的空間。

下載 Windows x64 ZIP ↓閱讀使用說明 ↗

Windows 10 / 11 x64 · 免安裝 ZIP

一張桌面，幾種可能。

01 / FEATURES
01

形狀自由拼排

六角形、朝上正三角形與 3:2 矩形。Shift 多選後一起拖曳，靠近其他格自動吸附。

02

放入當下需要的內容

顯示文字、PNG／JPEG／BMP 圖片，或正向與倒數計時器。

03

外觀各有自己的節奏

調整大小、字體、背景透明度，選擇實色、像素、RGB 或單色呼吸邊框。

04

版面可以一起帶走

匯出含圖片的 JSON；匯入時可覆蓋或合併，搬移時不用逐一找回圖片。

解壓縮，就能開始。

  1. 下載 Windows x64 ZIP，完整解壓縮。
  2. 開啟 DeskTiles 資料夾，雙擊 DeskTiles.exe。
  3. 選形狀並新增格子；編輯內容後按「套用至所有選取格」。

適用 Windows 10／11 x64，不需要 Visual Studio、Python、.NET 或額外執行套件，也不需要管理員權限。關閉控制面板只會隱藏視窗；要結束程式，請從右鍵或系統匣選「儲存並結束桌面拼格」。
