Choose your platform

Windows

Native C++17 / Win32 / GDI+. Includes text, images, timers, alarms, Traditional Chinese / English switching and optional sign-in launch with explicit consent.

Windows user guide ↗
Windows reminders and startup

Timers and alarms in other layouts keep running while the app is open. Reminders are unavailable while the app is fully closed. Start at sign-in remains off until you explicitly consent.

macOS

Native AppKit with the shared C++ core. Supports text, images, timers, group dragging, snapping and JSON layouts. The UI is Chinese; Windows alarms, language switching and sign-in launch are not available.

Universal 2 includes Apple silicon and Intel code. Intel hardware, multiple monitors and other macOS versions still need testing. The app is ad-hoc signed and has not been notarized by Apple.

Layout compatibility: Windows exports v3 and reads v1–v3. Mac exports and reads v1/v2 only; Windows v3 cannot be imported into Mac, even without alarms. Windows can import Mac v2.

Mac guide and limitations ↗

Three shapes, arranged your way

Text, images and timers

Keep a note, a picture or a timer in a hexagon, triangle or rectangle.

Select, drag and snap

Shift-select several tiles, move them together and snap near other tiles.

Style each tile

Adjust size, font, transparent backgrounds and solid, pixel, RGB or breathing borders.

Back up a layout

Export JSON with embedded images, then replace or merge on import. Mac cannot import Windows v3 layouts.

Start after downloading

Quit the previous app before updating and extract the full archive. Open DeskTiles/DeskTiles.exe on Windows or DeskTiles.app on Mac. Closing the controller hides it; use the app menu to save and exit.

Validation scope and limitations

The project reports 228 Windows core checks, 192 checks of the extracted package and 38 layout and CLI checks, plus 170 Mac core checks, Universal 2, icon loading and signature checks. The website publisher verifies the supplied files and hashes; it does not rerun the application tests.

The project confirmed that a background-layout alarm fired on schedule after an app restart. The Mac build is still unnotarized, with Intel hardware and multi-monitor testing pending. Linux is not available.
